# 会话记录：新增自定义工具（企业知识库搜索）

**日期**：2026-08-04  
**主题**：如何在尽量不改动 agentscope 源码的前提下，新增一个自定义工具（如企业知识库搜索，调接口）

---

## 用户问题

> 如果我想新增自定义工具，比如企业知识库搜索（调接口），但是我又想尽量不改动 agentscope 的源码，我应该如何改动

---

## 调研过程

通过阅读 agentscope 源码，确认了工具的扩展点架构：

- `src/agentscope/tool/__init__.py` —— 工具模块的对外入口，导出 ToolBase、FunctionTool、Toolkit 等
- `src/agentscope/tool/_base.py` —— ToolBase 抽象类，定义工具的协议接口（name、description、input_schema、call、check_permissions 等）
- `src/agentscope/tool/_adapters.py` —— FunctionTool 适配器，将普通 Python 函数包装为 ToolBase；MCPTool 适配 MCP 工具
- `src/agentscope/tool/_toolkit.py` —— Toolkit 核心类，负责工具的注册、管理、调用
- `tests/toolkit_test.py` —— 包含 ToolBase 子类的完整示例
- `scripts/model_examples/openai_chat_call.py` —— 包含 FunctionTool 的使用示例

核心发现：**agentscope 已经为自定义工具提供了清晰的扩展点，完全不需要修改源码。**

---

## 结论：三种扩展方式

### 方式一：`FunctionTool` 包装普通 Python 函数（最推荐）

适用于大多数"调 HTTP 接口"型工具。`FunctionTool` 会自动从函数签名和 docstring 提取 JSON Schema，把返回值转成 `ToolChunk`。

**示例代码：**

```python
# my_tools.py  ← 你自己的业务文件，不放在 agentscope 源码中
import httpx
from agentscope.tool import FunctionTool, Toolkit


def search_knowledge_base(
    query: str,
    top_k: int = 5,
) -> str:
    """搜索企业内部知识库，返回与查询最相关的文档片段。

    Args:
        query: 用户的查询语句。
        top_k: 返回的文档片段数量，默认 5。

    Returns:
        匹配到的文档片段，以 JSON 字符串形式返回。
    """
    resp = httpx.post(
        "https://kb.internal.company.com/api/search",
        json={"query": query, "top_k": top_k},
        timeout=10.0,
        headers={"Authorization": "Bearer xxx"},
    )
    resp.raise_for_status()
    return resp.text
```

**注册到 Agent：**

```python
from agentscope.agent import Agent
from agentscope.tool import Toolkit, FunctionTool

toolkit = Toolkit(tools=[FunctionTool(search_knowledge_base)])
agent = Agent(..., toolkit=toolkit)
```

**要点：**
- 支持 `def` 和 `async def`
- 返回值支持 `str`、可 JSON 序列化对象、`ToolChunk`、`AsyncGenerator`/`Generator`
- docstring 用 Google 风格 `Args:` 格式，会自动解析为 JSON Schema
- 可自定义名称：`FunctionTool(search_knowledge_base, name="kb_search", description="...")`
- 默认权限是 `ASK`，如需自动调用需额外配置 permission rule

### 方式二：继承 `ToolBase` 写完整工具类

适用于有复杂状态、需要自定义权限检查、或需要流式输出的场景。

**示例代码：**

```python
# my_tools.py
from typing import Any
import httpx
from agentscope.tool import ToolBase, ToolChunk
from agentscope.message import TextBlock, ToolResultState
from agentscope.permission import (
    PermissionDecision,
    PermissionBehavior,
    PermissionContext,
)


class KnowledgeBaseSearchTool(ToolBase):
    """企业知识库搜索工具。"""

    name: str = "kb_search"
    description: str = "在企业内部知识库中检索与用户问题相关的文档片段。"
    input_schema: dict[str, Any] = {
        "type": "object",
        "properties": {
            "query": {
                "type": "string",
                "description": "查询语句",
            },
            "top_k": {
                "type": "integer",
                "description": "返回的文档片段数量",
                "default": 5,
            },
        },
        "required": ["query"],
    }
    is_concurrency_safe: bool = True
    is_read_only: bool = True          # 只读，权限更宽松
    is_mcp: bool = False

    def __init__(self, api_base: str, api_key: str) -> None:
        super().__init__()
        self._api_base = api_base
        self._api_key = api_key

    async def check_permissions(
        self,
        tool_input: dict[str, Any],
        context: PermissionContext,
    ) -> PermissionDecision:
        # 只读工具，直接放行
        return PermissionDecision(
            behavior=PermissionBehavior.ALLOW,
            message="Knowledge base search is read-only.",
        )

    async def call(self, query: str, top_k: int = 5) -> ToolChunk:
        async with httpx.AsyncClient(timeout=10.0) as client:
            resp = await client.post(
                f"{self._api_base}/api/search",
                json={"query": query, "top_k": top_k},
                headers={"Authorization": f"Bearer {self._api_key}"},
            )
            resp.raise_for_status()
        return ToolChunk(
            content=[TextBlock(text=resp.text)],
            state=ToolResultState.RUNNING,
            is_last=True,
        )
```

**注册：**

```python
toolkit = Toolkit(tools=[
    KnowledgeBaseSearchTool(
        api_base="https://kb.internal.company.com",
        api_key="xxx",
    ),
])
```

**要点：**
- `call` 方法参数名必须与 `input_schema` 的 `properties` 一致
- 可返回单个 `ToolChunk` 或作为 `async generator` 实现流式输出
- 可直接在 `check_permissions` 中控制权限策略

---

### 方式三：通过 MCP 接入

如果已有 MCP server 封装了知识库接口，直接用 `MCPClient` 注册，完全不用写 Python 工具代码。

```python
from agentscope.mcp import MCPClient, StdioMCPConfig

kb_mcp = MCPClient(StdioMCPConfig(
    command="python",
    args=["-m", "my_kb_mcp_server"],
))
await kb_mcp.connect()

toolkit = Toolkit(mcps=[kb_mcp])
```

---

## 推荐选择

| 场景 | 推荐方式 |
|------|---------|
| 只是调 HTTP/API 接口 | 方式一 `FunctionTool`（10 行代码） |
| 需要自定义权限 / 流式输出 / 复杂状态 | 方式二 继承 `ToolBase` |
| 已有 MCP server | 方式三 `MCPClient` |

---

## 权限注意事项

- `FunctionTool` 默认权限是 `ASK`（`src/agentscope/tool/_adapters.py:103-107`），每次调用都会询问用户
- 如需 agent 自动调用，可以：
  1. 用方式二把 `check_permissions` 改为 `ALLOW`
  2. 或在 agent 的 permission engine 里添加 `PermissionRule(tool_name="search_knowledge_base", rule_content=None, behavior=PermissionBehavior.ALLOW)` 规则

三者均通过 `Toolkit(tools=[...])` 或 `Toolkit(mcps=[...])` 注入 `Agent`，全程不需要修改 `agentscope/` 下任何源码。
