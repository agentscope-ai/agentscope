# 延误补偿政策（节选）

适用于实物商品订单。以「承诺送达日」起算逾期天数，承诺送达日 =
下单日 + 订单上的 `promised_delivery_days`。

## 补偿档位

| 逾期天数 | 补偿 |
| --- | --- |
| 1–3 天 | 20 元无门槛优惠券 |
| 4–7 天 | 退还运费 + 50 元无门槛优惠券 |
| 8 天及以上，且仍未签收 | **可全额退款**，并补 50 元无门槛优惠券 |

## 约束

- 单笔订单的补偿总额不得超过「订单金额 + 50 元」。
- **全额退款必须经主管审批**，客服不得自行承诺。
- 优惠券有效期 90 天，不可折现。
- 补偿以订单为单位计算；同一客户的其他订单不合并计算，也不因本单
  延误而顺延。

## 不适用

- 已签收订单。
- 因客户填写地址错误、长期无人接收导致的延误。
- 生鲜、定制类商品另见《生鲜与定制商品条款》。
