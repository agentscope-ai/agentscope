# Prepared FastSandbox gateway template

Use [../build_template.py](../build_template.py) to build and validate this
recipe. It supplies a wheel from the current checkout and installs the gateway
and builtin-tool dependencies automatically. Optional `--requirements` packages
are installed into the same gateway venv.

See [OpenSandbox workspaces with FastSandbox](../../../../docs/opensandbox_fastsandbox.md#prepared-gateway-templates)
for local verification, full template publication, and workspace behavior.
