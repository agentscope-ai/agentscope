│   ├── __init__.py
│   └── provider_manager.py     ← ProviderManager (注册/切换/列表)
├── tools/                      ← 自定义工具开发目录
│   ├── __init__.py
│   ├── registry.py             ← ToolRegistry (增删查)
│   ├── builtin_tools.py        ← 示例工具 (@tool装饰)
│   └── custom/                 ← 你的产品工具放这里
├── middleware/                 ← 中间件开发目录
│   ├── __init__.py             ← 已扩展: 导出MiddlewareRegistry
│   ├── registry.py             ← Agent中间件注册表
│   ├── agent_middleware.py     ← 示例: LoggingMiddleware
│   ├── error_handler.py        ← (已有) ASGI错误处理
│   ├── request_log.py          ← (已有) ASGI访问日志
│   └── custom/                 ← 你的产品中间件放这里
├── routers/                    ← 自定义路由开发目录
│   ├── __init__.py             ← 已扩展: 导出新路由
│   ├── models.py               ← 模块7: 模型列表+切换 (/api/models)
│   ├── health.py               ← (已有) 健康检查
│   ├── stats.py                ← (已有) 示例路由

### 模块对应关系

| 计划# | 功能模块 | 实现文件 |
|--------|---------|---------|
| 1 | DeerFlow SSE 流式对话 | [deerflow/routers/deerflow_chat.py]（4 端点） |
| 2 | SSE 帧序列化 / 事件翻译 | [deerflow/protocol.py] + [deerflow/formatter.py] |
| 3 | 总线适配（回放 + 订阅） | [deerflow/bridge.py]（复用原生 MessageBus） |
| 4 | run 记账与状态机 | [deerflow/runs.py]（RunManager） |
| 5 | Agent 执行 | 原生 `ChatService`（与 `/chat/` 配置完全一致，无自研执行器） |
| 6 | 聊天会话管理 | AgentScope 内置 `/sessions` 路由 + [deerflow/routers/deerflow_chat.py] |
| 7 | 多模型路由 | [providers/provider_manager.py] + [routers/models.py] |
| 8 | 场景种子 | config.yaml agents 段 → lifespan 幂等同步进框架 StorageBase |

### API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/threads/{tid}/runs/stream` | POST | 创建 run + SSE 流式（deer-flow 协议） |
| `/api/threads/{tid}/runs/wait` | POST | 创建 run + 阻塞至完成 |
| `/api/threads/{tid}/runs/{rid}/stream` | GET | join 已有 run（回放 + 断线续传） |
| `/api/threads/{tid}/runs/{rid}/cancel` | POST | 取消 run（映射原生 interrupt） |
| `/api/models` | GET | 模型列表 |
| `/api/models/active` | POST | 切换活跃模型 |

> 已删除：`/api/chat/run` + `/api/chat/stop`（旧 Runtime 8 阶段编排 + Envelope 协议，2026-08 下线）

### 自定义开发指引

- **自定义工具**：在 `tools/builtin_tools.py` 或 `tools/custom/` 中用 `@tool` 装饰器添加，自动注册
- **自定义中间件**：在 `middleware/agent_middleware.py` 或 `middleware/custom/` 中继承 `Middleware`，通过 `MiddlewareRegistry.register()` 注册
- **自定义路由**：在 `routers/custom/` 中创建 `APIRouter`，在 `main.py` 中 `app.include_router()` 挂载
- **扩展 SSE 事件**：在 `deerflow/formatter.py` 的 `_on_<event_type>` handler 中新增映射（未知事件自动透传为 `custom`）
