### 模块对应关系

| 计划# | 功能模块 | 实现文件 |
|--------|---------|---------|
| 1 | 8阶段请求编排 | [runtime/runtime.py] |
| 2 | SSE事件信封 | [runtime/envelope.py]|
| 3 | Agent执行器 | [runtime/executor.py] |
| 4 | Agent组装器 | [runtime/builder.py] |

### API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/chat/run` | POST | SSE流式对话（Runtime 8阶段编排） |
| `/api/chat/stop` | POST | 停止对话（协作式取消） |
| `/api/agents` | GET/POST | Agent列表/创建 |
| `/api/agents/{id}` | GET/PUT/DELETE | Agent详情/更新/删除 |
| `/api/models` | GET | 模型列表 |
| `/api/models/active` | POST | 切换活跃模型 |

### 自定义开发指引

- **自定义工具**：在 `tools/builtin_tools.py` 或 `tools/custom/` 中用 `@tool` 装饰器添加，自动注册
- **自定义中间件**：在 `middleware/agent_middleware.py` 或 `middleware/custom/` 中继承 `Middleware`，通过 `MiddlewareRegistry.register()` 注册
- **自定义路由**：在 `routers/custom/` 中创建 `APIRouter`，在 `main.py` 中 `app.include_router()` 挂载
- **自定义钩子**：用 `@hook_registry.register(Phase.XXX)` 装饰器在 8 个阶段中的任意阶段插入逻辑
