
## 二、扩展点详解

### 2.1 自定义工具（最常用）

**扩展方式**：写 Python 函数 或 继承 `ToolBase`

**源码位置**：`src/agentscope/tool/_base.py`、`src/agentscope/tool/_adapters.py`

#### 方式 A：普通函数（最简单）

```python
from agentscope.tool import FunctionTool

def query_stock(product_id: str = "") -> str:
    """查询库存信息。
    
    Args:
        product_id: 产品ID，为空则查询全部
    
    Returns:
        JSON 格式的库存数据
    """
    data = [
        {"product_id": "P001", "name": "产品A", "stock": 100},
        {"product_id": "P002", "name": "产品B", "stock": 50},
    ]
    if product_id:
        data = [d for d in data if d["product_id"] == product_id]
    return json.dumps(data, ensure_ascii=False)

# 包装为 ToolBase
tool = FunctionTool(func=query_stock, is_read_only=True)
```

#### 方式 B：继承 ToolBase（复杂逻辑）

```python
from agentscope.tool import ToolBase
from agentscope.message import ToolChunk

class DatabaseQueryTool(ToolBase):
    name = "query_database"
    description = "执行 SQL 查询（只读）"
    input_schema = {
        "type": "object",
        "properties": {
            "sql": {"type": "string", "description": "SQL 查询语句"},
        },
        "required": ["sql"],
    }
    is_read_only = True
    is_concurrency_safe = True
    
    async def __call__(self, sql: str, **kwargs):
        # 流式返回结果
        async for chunk in execute_sql(sql):
            yield ToolChunk(text=chunk)
```

#### 注入方式：工具工厂

```python
async def create_my_tools(user_id: str, agent_id: str, session_id: str) -> list[ToolBase]:
    """根据用户/会话动态返回工具。"""
    tools = []
    
    # 按用户权限返回不同工具
    if user_id in ADMIN_USERS:
        tools.append(FunctionTool(func=delete_data))
    
    # 按部门返回不同工具
    dept = get_department(user_id)
    if dept == "sales":
        tools.append(FunctionTool(func=query_crm))
    
    return tools

# 注册到 create_app
app = create_app(
    ...,
    extra_agent_tools=create_my_tools,
)
```

**工厂签名**：`async (user_id, agent_id, session_id) -> list[ToolBase]`

**industry_agent 示例**：`main.py` 中的 `create_industry_tools` 按用户权限分组返回不同工具集。

### 2.2 自定义中间件（拦截/变换全流程）

**扩展方式**：继承 `MiddlewareBase`，覆写洋葱模型钩子

**源码位置**：`src/agentscope/middleware/_base.py`

#### 洋葱模型

```
用户消息进入
    │
    ▼
┌─────────────────────────────────────────┐
│  on_reply (最外层)                       │
│  ┌─────────────────────────────────────┐│
│  │  on_reasoning (推理阶段)             ││
│  │  ┌─────────────────────────────────┐││
│  │  │  on_model_call (模型API调用)     │││
│  │  │     ↓                           │││
│  │  │  模型返回                        │││
│  │  └─────────────────────────────────┘││
│  └─────────────────────────────────────┘│
│  ┌─────────────────────────────────────┐│
│  │  on_acting (工具执行，每个工具一次)   ││
│  │     ↓                               ││
│  │  工具返回结果                        ││
│  └─────────────────────────────────────┘│
│  循环直到无工具调用                       │
└─────────────────────────────────────────┘
    │
    ▼
回复消息输出
```

#### 5 个钩子方法

| 钩子 | 拦截什么 | 典型用途 |
|------|---------|---------|
| `on_reply` | 整个回复流程 | 计时、日志、限流 |
| `on_reasoning` | 模型推理阶段 | 注入额外上下文、修改模型输入 |
| `on_acting` | 单个工具执行 | 审计、权限过滤、结果变换 |
| `on_model_call` | 原始 API 调用 | 重试、降级、缓存 |
| `on_system_prompt` | 系统提示词 | 动态注入用户信息、时间等 |

#### 示例：审计中间件

```python
from agentscope.middleware import MiddlewareBase

class AuditMiddleware(MiddlewareBase):
    """记录所有工具调用到数据库。"""
    
    async def on_acting(self, agent, input_kwargs, next_handler):
        tool_call = input_kwargs.get("tool_call")
        
        # 工具执行前
        start_time = time.time()
        print(f"[AUDIT] 开始: {tool_call.name}")
        
        # 执行工具（透传）
        results = []
        async for chunk in next_handler():
            results.append(chunk)
            yield chunk
        
        # 工具执行后
        duration = time.time() - start_time
        await save_audit_log(
            user_id=agent.state.user_id,
            tool_name=tool_call.name,
            duration=duration,
        )
```

#### 示例：数据权限过滤中间件

```python
class DataPermissionMiddleware(MiddlewareBase):
    """按用户权限过滤工具返回的数据。"""
    
    async def on_acting(self, agent, input_kwargs, next_handler):
        tool_call = input_kwargs.get("tool_call")
        
        async for chunk in next_handler():
            if hasattr(chunk, "text") and chunk.text:
                try:
                    data = json.loads(chunk.text)
                    if isinstance(data, list):
                        # 按用户权限过滤行
                        filtered = filter_by_permission(
                            data, 
                            user_id=get_user_id(agent),
                        )
                        chunk.text = json.dumps(filtered, ensure_ascii=False)
                except (json.JSONDecodeError, AttributeError):
                    pass
            yield chunk
```

#### 示例：动态系统提示词

```python
class ContextInjectionMiddleware(MiddlewareBase):
    """在系统提示词中注入当前时间和用户信息。"""
    
    async def on_system_prompt(self, agent, current_prompt) -> str:
        user_info = await get_user_info(agent.state.user_id)
        return (
            f"{current_prompt}\n\n"
            f"当前时间: {datetime.now().isoformat()}\n"
            f"当前用户: {user_info['name']}（{user_info['department']}）"
        )
```

#### 注入方式

```python
async def create_my_middlewares(user_id, agent_id, session_id):
    middlewares = [AuditMiddleware()]
    
    if user_id == "admin":
        middlewares.append(DataPermissionMiddleware())

app = create_app(
    ...,
    extra_agent_middlewares=create_my_middlewares,

```

**工厂签名**：`async (user_id, agent_id, session_id) -> list[MiddlewareBase]`

**运行时检测**：框架通过 `is_implemented(hook_name)` 自动检测子类实现了哪些钩子，只注册有实现的钩子，避免不必要的调用开销。

```python
from agentscope.model import ChatModelBase
from agentscope.model._model_response import ChatResponse, StructuredResponse
from agentscope.credential import CredentialBase

class MyLLMCredential(CredentialBase):
    type: Literal["my_llm"] = "my_llm"
    api_key: str
    endpoint: str

class MyLLMModel(ChatModelBase):
    type: Literal["my_llm"] = "my_llm"
    
    class Parameters(BaseModel):
        max_tokens: int | None = None
        temperature: float | None = None
    
    async def _call_api(self, model_name, messages, tools=None, **kwargs):
        # 调用自己的模型 API
        response = await httpx.post(
            self.credential.endpoint,
            headers={"Authorization": f"Bearer {self.credential.api_key}"},
            json={
                "model": model_name,
                "messages": messages,
                "tools": tools,
                **kwargs,
            },
        )
        return self._parse_response(response.json())
    
    def _parse_response(self, data) -> ChatResponse:
        # 将 API 响应转换为框架标准格式
        return ChatResponse(
            content=[TextBlock(text=data["choices"][0]["message"]["content"])],
            is_last=True,
        )
```

## 四、扩展点优先级与冲突处理

### 4.1 中间件执行顺序

```
框架内置中间件（固定顺序）
    ├── InboxMiddleware          # 消息投递
    ├── StateChangeMiddleware    # 状态变更通知
    └── ToolOffloadMiddleware    # 长任务卸载

用户自定义中间件（按工厂返回顺序）
    ├── AuditMiddleware
    ├── DataPermissionMiddleware
    └── ...

框架可选中间件（按条件注入）
    ├── TTSMiddleware            # 有 TTS 配置时
    └── RAGMiddleware            # 有知识库配置时
```

### 4.2 工具冲突处理

当自定义工具与内置工具同名时：

```python
# toolkit 注册时检测
if tool_name in available_tools:
    logger.warning(f"Duplicate tool name '{tool_name}', overwriting.")
```

**规则**：后注册的覆盖先注册的。自定义工具（通过工厂注入）优先级高于内置工具。

## 五、面试要点

### 5.1 框架的扩展性设计思路？

**答**：
1. **工厂模式**：工具和中间件通过异步工厂动态注入，支持按用户/会话差异化
2. **洋葱模型**：中间件采用洋葱式钩子，可拦截任意阶段
3. **抽象基类**：存储、工作空间、模型等核心组件都定义了抽象接口
4. **依赖注入**：`create_app()` 通过参数注入所有组件，松耦合
5. **运行时检测**：`is_implemented()` 自动检测中间件实现了哪些钩子

### 5.2 如何实现多租户工具隔离？

**答**：
通过 `extra_agent_tools` 工厂函数，根据 `user_id` 返回不同工具集：

```python
async def create_tools(user_id, agent_id, session_id):
    perms = await get_permissions(user_id)
    return [FunctionTool(func=f) for f in TOOL_GROUPS[perms]]
```

### 5.3 如何对接公司内部大模型？

**答**：
1. 继承 `CredentialBase` 定义凭证类型
2. 继承 `ChatModelBase` 实现 `_call_api` 方法
3. 通过 `extra_credentials` 注册
4. 前端创建凭证时选择新类型，创建 Session 时引用
