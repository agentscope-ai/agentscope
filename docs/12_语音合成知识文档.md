## 一、核心概念

### 1.1 什么是 TTS 模块？

**TTS（Text-to-Speech，文本转语音）** 是 AgentScope 中用于**将 Agent 的文本输出转换为语音音频**的模块。

它提供统一的接口封装不同厂商的 TTS API：

```
┌─────────────────────────────────────────────────────────────┐
│                    TTSModelBase（抽象基类）                   │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │ OpenAI      │  │ DashScope   │  │ DashScope   │         │
│  │ TTSModel    │  │ TTSModel    │  │ CosyVoice   │         │
│  │             │  │             │  │ TTSModel    │         │
│  └─────────────┘  └─────────────┘  └─────────────┘         │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ DashScopeRealtimeTTSModel（实时流式输入）             │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

**关键理解** 🔴：
- **统一接口**：所有 TTS 模型继承 `TTSModelBase`，对外暴露相同的 API
- **两种模式**：
  - **non-realtime**：调用 `synthesize(text)` 一次性合成完整音频
  - **realtime**：通过 `push(text)` 增量推送文本，`synthesize()` 等待完整音频
- **中间件集成**：通过 `TTSMiddleware` 自动拦截 Agent 文本输出并合成语音
- **适配器模式**：各厂商的 SDK 差异封装在子类中

---

### 1.2 为什么需要 TTS 模块？

| 需求 | 没有 TTS 模块 | 有 TTS 模块 |
|------|-------------|-----------|
| 语音输出 | 手动调用各厂商 API | 统一 `synthesize()` 接口 |
| 流式合成 | 每个厂商不同实现 | 统一 `AsyncGenerator` |
| 实时交互 | 需要自行处理 WebSocket | `realtime` 模式内置支持 |
| 中间件集成 | 修改 Agent 代码 | 挂载 `TTSMiddleware` |

**核心矛盾**：
- 不同厂商的 TTS API 格式、参数、错误处理各不相同
- Agent 需要统一的语音合成接口

**AgentScope 的解法**：模板方法模式 + 适配器模式 + 中间件集成

## 二、核心接口 / 类型定义

### 2.1 TTSModelBase（抽象基类）

```python
class TTSModelBase:
    """TTS 模型基类"""
    
    credential: CredentialBase      # API 凭证
    model: str                      # 模型名称
    parameters: BaseModel           # 模型参数
    stream: bool                    # 是否流式输出
    realtime: bool = False          # 是否实时模式（流式输入）

    # === 核心方法 ===
    async def synthesize(text: str) -> TTSResponse
        """合成完整语音（non-realtime 模式必须实现）"""
    
    # === 实时模式方法（realtime=True 时实现）===
    async def connect() -> None
        """建立连接（WebSocket 等）"""
    
    async def push(text: str) -> TTSResponse | None
        """推送文本片段，返回当前可用音频（可能为 None）"""
    
    async def close() -> None
        """关闭连接"""
    
    # === 异步上下文管理器 ===
    async def __aenter__() -> "TTSModelBase"
    async def __aexit__() -> None
```

**关键区别** 🔴：

| 方法 | 模式 | 用途 |
|------|------|------|
| `synthesize()` | non-realtime | 一次性合成完整音频 |
| `connect()` + `push()` + `close()` | realtime | 流式输入，增量合成 |
| `__aenter__` / `__aexit__` | realtime | 自动管理连接生命周期 |

### 2.2 TTSResponse 和 TTSUsage

```python
@dataclass
class TTSUsage:
    input_tokens: int       # 输入文本 token 数
    output_tokens: int      # 输出音频 token 数
    time: float             # 合成耗时（秒）

@dataclass
class TTSResponse:
    content: DataBlock | None   # 音频数据（Base64 编码）
    is_last: bool               # 是否为最后一个 chunk
    usage: TTSUsage | None      # Token 使用统计
```

### 2.3 使用示例

#### non-realtime 模式

```python
from agentscope.tts import OpenAITTSModel
from agentscope.credential import OpenAICredential

tts_model = OpenAITTSModel(
    credential=OpenAICredential(api_key="sk-..."),
    model="tts-1",
    parameters=OpenAITTSModel.Parameters(
        voice="alloy",
        response_format="mp3",
    ),
    stream=True,
)

# 一次性合成
response = await tts_model.synthesize("你好，世界！")
if response.content:
    audio_data = response.content.source.data  # Base64 编码的音频
```

#### realtime 模式

```python
from agentscope.tts import DashScopeRealtimeTTSModel

tts_model = DashScopeRealtimeTTSModel(
    credential=DashScopeCredential(api_key="..."),
    model="qwen3-tts-flash-realtime",
    stream=True,
)

# 实时流式输入
async with tts_model:
    # 推送文本片段
    await tts_model.push("你好，")
    await tts_model.push("这是一个")
    await tts_model.push("实时语音合成示例。")
    
    # 等待完整音频
    response = await tts_model.synthesize("")
    if response.content:
        audio_data = response.content.source.data
```

## 三、设计原理

### 3.1 架构设计

```
┌─────────────────────────────────────────────────────────────┐
│  1. 接口层（TTSModelBase）                                   │
│     - synthesize()：合成完整语音                             │
│     - push() / connect() / close()：实时模式                 │
└─────────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│  2. 适配层（各厂商实现）                                      │
│     - OpenAITTSModel._call_api()                            │
│     - DashScopeTTSModel._call_api()                         │
│     - DashScopeRealtimeTTSModel._call_api()                 │
└─────────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│  3. 响应类型（TTSResponse）                                   │
│     - content: DataBlock（Base64 音频）                      │
│     - usage: TTSUsage                                        │
│     - is_last: bool                                          │
└─────────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│  4. 中间件集成（TTSMiddleware）                               │
│     - 拦截 TextBlockDeltaEvent / TextBlockEndEvent          │
│     - 调用 TTS 模型合成语音                                  │
│     - 注入 DATA_BLOCK_* 事件到事件流                         │
└─────────────────────────────────────────────────────────────┘
```

---

### 3.2 两种模式对比

| 特性 | non-realtime | realtime |
|------|-------------|----------|
| **输入方式** | 一次性传入完整文本 | 增量推送文本片段 |
| **输出方式** | 一次性返回完整音频 | 流式返回音频 chunk |
| **延迟** | 较高（等待完整文本） | 较低（边输入边合成） |
| **适用场景** | 静态文本合成 | 实时交互、流式输出 |
| **实现复杂度** | 简单 | 复杂（需管理连接状态） |
| **代表模型** | OpenAI tts-1、DashScope qwen3-tts-flash | DashScope qwen3-tts-flash-realtime |

```python
class GeminiTTSModel(TTSModelBase):
    """Gemini TTS 实现（src/agentscope/tts/_gemini/_model.py）"""

    type: Literal["gemini_tts"] = "gemini_tts"

                 stream=False,         # True 时 synthesize 返回 AsyncGenerator
                 client_kwargs=None): ...
```

**设计要点**：
- **PCM → WAV 包装**：Gemini 返回裸 PCM（24kHz mono 16-bit），非流式模式用 `wave` 模块包成自包含 WAV；与 DashScopeTTS 的处理策略一致
- **流式 WAV 头**：`stream=True` 时首个 chunk 前置 `_build_streaming_wav_header()`（RIFF 头声明未知长度），前端**无需等流结束即可开播**，后续 chunk 为裸 PCM 追加
- **is_last 延迟标记**：用 `pending` 变量缓存上一 chunk，流结束时才对最后一个 chunk 置 `is_last=True` 并附加 usage——因为迭代中无法预知哪个是最后一个
- **SDK 版本防御**：`inline_data.data` 可能是 base64 str 或 raw bytes（google-genai 版本差异），isinstance 双分支处理
- **usage 计量**：从 `usage_metadata` 提取 prompt/candidates token 数

**TTS 实现清单（含 main）**：OpenAITTSModel、DashScopeTTSModel、DashScopeRealtimeTTSModel、**GeminiTTSModel** ⚠️（目录 `src/agentscope/tts/_gemini/`，模型卡 yaml 2 个）

### 4.3 TTSMiddleware 实现

```python
class TTSMiddleware(MiddlewareBase):
    """TTS 中间件：拦截文本输出并合成语音"""
    
    def __init__(self, tts_model: TTSModelBase):
        self._tts_model = tts_model
    
    async def on_reply(self, agent, input_kwargs, next_handler):
        # 标准模式（realtime=False）：
        # - 累积文本直到 TextBlockEndEvent
        # - 一次性合成完整音频
        # - 注入 DATA_BLOCK_* 事件
        
        # 实时模式（realtime=True）：
        # - 每个 TextBlockDeltaEvent 即时推送
        # - 音频 chunk 与文本交替并发输出
        
        text_buffer = []
        async for event in next_handler(**input_kwargs):
            yield event
            
            if isinstance(event, TextBlockDeltaEvent):
                text_buffer.append(event.delta)
                
                if self._tts_model.realtime:
                    # 实时模式：即时推送
                    response = await self._tts_model.push(event.delta)
                    if response and response.content:
                        yield self._build_audio_event(response)
            
            elif isinstance(event, TextBlockEndEvent):
                if not self._tts_model.realtime:
                    # 标准模式：一次性合成
                    full_text = "".join(text_buffer)
                    response = await self._tts_model.synthesize(full_text)
                    if response.content:
                        yield self._build_audio_event(response)
                text_buffer.clear()
    
    def _build_audio_event(self, response: TTSResponse) -> DataBlockStartEvent:
```

## 五、使用示例

### 5.1 基础使用：Agent 语音输出

```python
from agentscope.agent import Agent
from agentscope.tts import OpenAITTSModel
from agentscope.middleware import TTSMiddleware

# 创建 TTS 模型
tts_model = OpenAITTSModel(
    credential=OpenAICredential(api_key="sk-..."),
    model="tts-1",
    parameters=OpenAITTSModel.Parameters(voice="alloy"),
)

# 创建 Agent，挂载 TTS 中间件
agent = Agent(
    name="assistant",
    model=chat_model,
    middlewares=[TTSMiddleware(tts_model)],
)

# Agent 的文本输出会自动合成语音
async for event in agent.reply_stream(UserMsg("user", "讲个故事")):
    if isinstance(event, TextBlockDeltaEvent):
        print(event.delta, end="", flush=True)
    elif isinstance(event, DataBlockStartEvent):
        # 音频数据
        audio_data = event.content.source.data
```

## 六、关键点总结

### 6.1 核心设计思想

| 设计点 | 说明 |
|--------|------|
| **统一接口** | 所有 TTS 模型继承 `TTSModelBase`，对外暴露相同 API |
| **两种模式** | non-realtime（一次性合成）和 realtime（流式输入） |
| **适配器模式** | 各厂商 SDK 差异封装在子类中 |
| **中间件集成** | 通过 `TTSMiddleware` 零侵入集成到 Agent |
| **异步上下文管理器** | realtime 模式自动管理连接生命周期 |

---

### 6.2 与其他框架对比

| 框架 | TTS 抽象 | 特点 |
|------|---------|------|
| **AgentScope** | ✅ 完整（统一接口 + 中间件） | 支持 realtime 模式、多厂商适配 |
| **LangChain** | ⚠️ 基础 | 通过 `TextToSpeechTool` 集成，无统一抽象 |
| **Semantic Kernel** | ⚠️ 有限 | 插件形式，无流式支持 |
| **OpenAI SDK** | 无 | 只支持 OpenAI，无抽象 |

## 八、最佳实践

### 8.1 开发建议

1. **选择合适的模式**：
   - 静态文本 → non-realtime
   - 实时交互 → realtime

2. **配置合理的 voice**：
   - 不同场景使用不同音色
   - 考虑目标受众的偏好

3. **处理音频数据**：
   - Base64 解码后保存或播放
   - 注意音频格式（mp3/wav/pcm）

---

### 8.2 性能优化

1. **流式输出**：使用 realtime 模式降低延迟
2. **连接复用**：realtime 模式使用 `async with` 管理连接
3. **批量合成**：non-realtime 模式可批量处理多个文本
