## 7. 简答参考

### Stop 题参考

```text
running：通过 CancelDispatcher 找到对应进程或本地 task，触发 asyncio cancel。
parked：没有 running task，注入 UserInterruptEvent 作为 resume trigger。
idle：对存在 session 是 no-op，保证幂等。
最终：finally 清理状态，SSE 收尾，前端回 idle。
```

### RAG 题参考

```text
上传只保存原始文件和 pending record；IndexWorker 后台 parse、chunk、embedding、insert vector store；状态通过 polling 暴露给前端。
```

### 多 Agent 题参考

```text
leader 和 worker 是独立 agent/session/state，通过模板创建和 MessageBus 通信，便于隔离、恢复、审计和前端可视化。
```

### 企业权限题参考

```text
默认 owner-isolated；跨 owner 共享由 ResourceAccessPolicy 返回 ResourceRef；READ/EDIT 分离；credential view 脱敏；后端 resolve_for_edit 强校验。
```
