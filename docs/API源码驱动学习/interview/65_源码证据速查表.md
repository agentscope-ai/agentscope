# 源码证据速查表

> 适合面试表达的关键词：源码入口、证据、快速定位、答辩、追问。

---

## 1. 使用方式

面试或复习时，如果你讲了某个设计点，最好能补一句：

```text
这个点可以从某某源码入口看到。
```

这份表就是为了快速定位源码证据。
