## 3. 面试回答结构

回答任何模块都按这个顺序：

```text
1. 产品问题是什么。
2. 系统难点是什么。
3. AgentScope 怎么设计。
4. 源码入口在哪里。
5. 这个设计有什么 trade-off。
6. 如果让我优化，我会补什么。
```

示例：优雅终止

```text
产品问题是用户点 Stop 后要可靠停止当前回答，不能卡住 UI，也不能丢状态。
难点是 Agent run 可能在另一个进程，可能正在模型流式输出，也可能停在 HITL。
AgentScope 用 202 异步控制命令，running 时广播 interrupt 让持有 task 的 worker 协作式 cancel，parked 时投 UserInterruptEvent 唤醒关闭。
关键源码是 ChatService.interrupt、CancelDispatcher、Agent._reply_impl 和 useMessages。
trade-off 是链路比同步 cancel 复杂，但支持跨进程和状态一致。
如果优化，我会补 Router 层测试和用户可见的中断失败提示。
```

## 5. 最后提醒

面试时不要说：

```text
我看过某某文件，里面有某某函数。
```

要说：

```text
这个系统为什么需要这样设计。
它解决了什么用户和工程问题。
源码里如何把这个设计落到接口、状态、事件和测试。
```
