## 3. Stop / Interrupt

中文思路：

```text
Stop 是异步控制命令，返回 202，后端通过 cancel 或 resume interrupt 收尾。
```

English answer:

```text
The stop action is modeled as an asynchronous control command. The API returns HTTP 202 because cancellation is not completed synchronously. If the session is currently running, the backend broadcasts a cancellation signal and cancels the in-flight asyncio task. If the session is parked for HITL, there is no running task to cancel, so the system enqueues a resume interrupt event. In both cases, the agent cleans up through finally blocks and the frontend observes the final state through SSE.
```

关键词：

```text
asynchronous control command
HTTP 202 Accepted
cooperative cancellation
asyncio.CancelledError
parked session
SSE finalization
```

## 4. RAG 上传和异步索引

中文思路：

```text
上传和索引解耦，上传只保存 bytes 和 pending 状态，worker 后台处理。
```

English answer:

```text
Document upload and indexing are intentionally decoupled. The upload API only persists the raw bytes into BlobStore and creates a document record in the pending state. The expensive pipeline, including parsing, chunking, embedding, and vector-store insertion, is handled asynchronously by an index worker. This avoids blocking the API request and makes the indexing process observable through document states such as pending, parsing, chunking, indexing, ready, and error.
```

关键词：

```text
decoupled upload and indexing
BlobStore
IndexWorker
lease and heartbeat
vector-store insertion
observable document lifecycle
```

## 6. Multi-Agent

中文思路：

```text
多 Agent 是多个 session 的协作拓扑，不是内存函数调用。
```

English answer:

```text
Multi-agent collaboration is modeled as a topology of multiple agents and sessions, rather than direct in-memory function calls. A leader agent can create worker agents from predefined templates. Each worker has its own session, state, permission context, and execution lifecycle. Communication happens through team messaging and the message bus, which makes the system easier to isolate, audit, recover, and visualize in the UI.
```

关键词：

```text
agent topology
leader-worker collaboration
sub-agent templates
isolated session state
auditable communication
```

## 7. HITL

中文思路：

```text
HITL 难点是 parked session 如何可靠恢复。
```

English answer:

```text
The core challenge of human-in-the-loop is not showing a confirmation dialog. The real challenge is how to reliably resume a parked agent run. When a tool call requires confirmation, the agent emits a confirmation event and parks the session. After the user approves or rejects the action, the result is delivered back as a resume trigger. The dispatcher must preserve resume triggers because they carry user decisions.
```

关键词：

```text
human-in-the-loop
confirmation event
parked run
resume trigger
user decision
```

## 8. 企业权限

中文思路：

```text
默认 owner-isolated，企业共享通过 ResourceAccessPolicy。
```

English answer:

```text
The default access model is owner-isolated. Each resource is stored under an owner user id. Cross-owner sharing is implemented through a ResourceAccessPolicy, which returns resource references with read or edit permission. API views include an editable flag, and credentials are masked in shared views. This keeps the default behavior secure while allowing enterprise-specific sharing policies to be plugged in.
```

关键词：

```text
owner-isolated storage
cross-owner sharing
ResourceAccessPolicy
read/edit permission
credential masking
```

## 9. 成本治理

中文思路：

```text
按 reply 维度累计 token，超预算后强制收尾。
```

English answer:

```text
Cost governance should be done at multiple levels. At the reply level, the budget middleware listens to model-call-end events and accumulates weighted input and output tokens. Once the budget is exceeded, it injects a hint into the context and forces tool_choice to none, so the agent wraps up instead of continuing to call tools. At a higher level, we can add per-user or per-tenant quotas, limit RAG top_k, tool output size, retry count, fallback usage, and the number of worker agents.
```

关键词：

```text
token budget
weighted token cost
tool_choice none
tenant quota
cost attribution
```
