## 一、MCP Server 写法（FastMCP）

### 1.1 安装

```bash
pip install "mcp[cli]"
```

### 1.2 核心概念

FastMCP 有三大能力：

| 能力 | 装饰器 | 用途 | LLM 视角 |
|------|--------|------|----------|
| Tool | `@mcp.tool()` | 执行操作、计算 | 可调用函数 |
| Resource | `@mcp.resource(uri)` | 读取数据 | 可读取文件 |
| Prompt | `@mcp.prompt()` | 提示词模板 | 预设对话模板 |

### 1.3 完整示例

```python
from mcp.server import FastMCP
from pydantic import BaseModel, Field

mcp = FastMCP("孕产助手")

# ---- Tool ----
@mcp.tool()
def calculate_due_date(last_period: str) -> str:
    """根据末次月经计算预产期。

    Args:
        last_period: 末次月经日期，格式 YYYY-MM-DD
    """
    from datetime import datetime, timedelta
    lmp = datetime.strptime(last_period, "%Y-%m-%d")
    edd = lmp + timedelta(days=280)
    return f"预产期为：{edd.strftime('%Y-%m-%d')}"

# ---- 异步 Tool ----
@mcp.tool()
async def check_fetal_heart_rate(gestational_week: int) -> str:
    """查询不同孕周的胎儿心率正常范围。

    Args:
        gestational_week: 孕周数
    """
    return f"孕{gestational_week}周正常心率：110-160 bpm"

# ---- 用 Pydantic 模型做复杂参数 ----
class SymptomQuery(BaseModel):
    symptom: str = Field(description="症状描述")
    trimester: str = Field(description="孕早期/孕中期/孕晚期")

@mcp.tool()
def check_symptom_risk(query: SymptomQuery) -> str:
    """检查孕期症状的风险等级。"""
    return f"症状[{query.symptom}]在{query.trimester}的风险评估：低风险"

# ---- Resource ----
@mcp.resource("guide://trimester/{trimester}")
def trimester_guide(trimester: str) -> str:
    """获取孕三期注意事项"""
    guides = {
        "孕早期": "1.补充叶酸 2.避免辐射 3.注意休息",
        "孕中期": "1.均衡饮食 2.适量运动 3.按时产检",
        "孕晚期": "1.数胎动 2.准备待产包 3.注意临产信号",
    }
    return guides.get(trimester, "请确认孕阶段")

# ---- Prompt 模板 ----
@mcp.prompt()
def prenatal_checkup_reminder(trimester: str) -> str:
    """生成产检提醒话术。

    Args:
        trimester: 孕早期/孕中期/孕晚期
    """
    schedules = {
        "孕早期": "NT 检查 (11-13 周)、建档",
        "孕中期": "唐筛 (15-20 周)、大排畸 (22-26 周)、糖耐 (24-28 周)",
        "孕晚期": "胎心监护 (34 周起)、GBS 筛查 (35-37 周)",
    }
    return f"【{trimester}产检提醒】\n{schedules.get(trimester, '请确认孕周')}"

if __name__ == "__main__":
    # 选一种传输方式运行
    mcp.run(transport="streamable-http", host="0.0.0.0", port=8000)
    # mcp.run(transport="sse", host="0.0.0.0", port=8000)
    # mcp.run(transport="stdio")
```

## 二、三种传输方式对比

| | **stdio** | **SSE** | **Streamable HTTP** |
|---|---|---|---|
| **通信方式** | 标准输入/输出管道 | HTTP + Server-Sent Events 长连接 | 普通 HTTP POST + 可选 SSE |
| **部署形态** | 本地进程，宿主启动子进程 | 远程 HTTP 服务 | 远程 HTTP 服务 |
| **连接模型** | 1 对 1，进程绑定 | 1 对多，长连接保持 | 1 对多，无状态（可切有状态） |
| **需要端口** | 不需要 | 需要 | 需要 |
| **跨网络** | 不支持 | 支持 | 支持 |
| **断线重连** | 进程挂了就没了 | 需要重连整个 SSE 流 | 每次请求独立，天然容错 |
| **代理/CDN** | 不支持 | 长连接容易被代理断开 | 普通 HTTP，兼容性好 |
| **状态管理** | 天然有状态（进程内存） | 有状态（连接绑定） | 默认无状态，可选有状态 |
| **适用场景** | 本地工具（Claude Desktop、IDE 插件） | 远程服务（旧标准） | 远程服务（新标准，推荐） |

### 选择建议

| 场景 | 选哪个 |
|------|--------|
| 本地 IDE 插件 / Claude Desktop | `stdio` |
| 远程服务，需要兼容旧客户端 | `sse` |
| 远程服务，新项目 | `streamable-http` |
| 需要部署到生产环境 | `streamable-http` |
| 需要多客户端 / 水平扩展 | `streamable-http` |

**一句话总结**：本地用 stdio，远程用 streamable-http，sse 是过渡方案可以不用管了。

## 三、MCP Client 调用方式

### 方式 A：直接用 MCPClient（手动调用）

```python
import asyncio
from agentscope.mcp import MCPClient, HttpMCPConfig

async def main():
    client = MCPClient(
        name="my-client",
        is_stateful=False,
        mcp_config=HttpMCPConfig(
            type="http_mcp",
            url="http://localhost:8000/mcp",
        ),
    )

    # 获取工具并调用
    add_tool = await client.get_tool("add")
    result = await add_tool(a=1, b=2)
    print(result.content[0].text)  # "3"

asyncio.run(main())
```

**特点**：
- 你写代码决定调什么工具
- 返回 `ToolChunk`（原始结果）
- 适合：脚本、测试、固定流程

---

### 方式 B：Toolkit 集成（LLM 自主调用）

```python
from agentscope.mcp import MCPClient, HttpMCPConfig
from agentscope.tool import Toolkit

# 创建 MCP 客户端
mcp_client = MCPClient(
    name="demo",
    is_stateful=False,
    mcp_config=HttpMCPConfig(url="http://localhost:8000/mcp"),
)

# 注册到 Toolkit
toolkit = Toolkit(mcps=[mcp_client])

# 获取所有工具 schema（给 LLM 用）
schemas = await toolkit.get_tool_schemas()
# 输出：[{"type": "function", "function": {"name": "mcp__demo__add", ...}}, ...]
```

**特点**：
- LLM 根据 schema 自己选工具
- 返回 `ToolResponse`（Agent 格式）
- 适合：Agent 场景

---

### 方式 C：官方 SDK ClientSession（底层协议）

```python
import asyncio
from mcp import ClientSession
from mcp.client.streamable_http import streamablehttp_client

async def test():
    url = "http://localhost:8000/mcp"
    async with streamablehttp_client(url) as (read, write, _):
        async with ClientSession(read, write) as session:
            await session.initialize()

            # 列出工具
            tools = await session.list_tools()
            for t in tools.tools:
                print(f"  {t.name}: {t.description}")

            # 调用工具
            result = await session.call_tool("add", {"a": 10, "b": 20})
            print(f"  结果：{result.content[0].text}")

asyncio.run(test())
```

**特点**：
- 最底层，直接操作 JSON-RPC
- 适合：调试协议层问题、跨语言

### 方式 D：AgentScope App（平台全包）

```python
from agentscope.app import create_app, SubAgentTemplate
from agentscope.mcp import MCPClient, HttpMCPConfig

app = create_app(
    workspace_manager=LocalWorkspaceManager(
        default_mcps=[
            MCPClient(name="demo", mcp_config=HttpMCPConfig(url="..."))
        ],
    ),
)
```

**特点**：
- 平台自动管理 MCP 生命周期
- 自动注入到每个 Agent 的 workspace
- 适合：多 Agent 平台

### 四种方式对比

| | **A. MCPClient** | **B. Toolkit** | **C. ClientSession** | **D. AgentScope App** |
|---|---|---|---|---|
| **控制方** | 开发者代码 | LLM 决策 | 开发者代码 | 平台自动 |
| **依赖** | agentscope | agentscope | 仅 mcp SDK | agentscope 全套 |
| **抽象层级** | 中 | 中高 | 低（原始协议） | 最高 |
| **工具命名** | 原名 | `mcp__{client}__{tool}` | 原名 | 自动加前缀 |
| **状态管理** | 手动 connect/close | Toolkit 管理 | 手动 session | 平台管理 |
| **多 MCP 管理** | 每个单独操作 | 统一注册 | 每个单独操作 | 自动注入 workspace |
| **LLM 参与** | 不需要 | 需要 | 不需要 | 需要 |
| **典型场景** | 脚本/测试 | 单 Agent 调用工具 | 底层调试/跨语言 | 多 Agent 平台 |

## 五、自定义 Agent 写法

### 写法 1：直接用 Agent 类（不需要 server）

```python
# my_agent.py
import asyncio
from agentscope.agent import Agent
from agentscope.message import UserMsg
from agentscope.tool import Toolkit
from agentscope.mcp import MCPClient, HttpMCPConfig
from agentscope.model import OpenAIChatModel
from agentscope.credential import OpenAICredential

async def main():
    # 1. 创建 MCP 客户端
    mcp_client = MCPClient(
        name="pregnancy_mcp",
        mcp_config=HttpMCPConfig(url="http://localhost:8000/mcp"),
    )
    
    # 2. 创建 Toolkit
    toolkit = Toolkit(mcps=[mcp_client])
    
    # 3. 创建模型
    model = OpenAIChatModel(
        credential=OpenAICredential(api_key="sk-xxx"),
        model="gpt-4",
    )
    
    # 4. 创建 Agent
    agent = Agent(
        name="孕产助手",
        system_prompt="你是专业的孕产顾问...",
        model=model,
        toolkit=toolkit,
    )
    
    # 5. 对话
    reply = await agent.reply(UserMsg("user", "孕早期要注意什么？"))
    print(reply.get_text_content())

asyncio.run(main())
```

**运行**：`python my_agent.py`

**不需要 server，不需要 WebUI**，纯 Python 脚本。

---

### 写法 2：通过 create_app 注册（需要 server + WebUI）

```python
# main.py
from agentscope.app import create_app, SubAgentTemplate

app = create_app(
    custom_subagent_templates=[
        SubAgentTemplate(
            type="pregnancy_advisor",
            description="孕产顾问",
            system_prompt_template="你是专业的孕产顾问...",
        ),
    ],
)

if __name__ == "__main__":
    import uvicorn
    uvicorn.run("main:app", port=8000)
```

**运行**：
```bash
python main.py              # 启动 server
cd examples/web_ui && pnpm dev  # 启动 WebUI
```

然后在 WebUI 里创建 Agent、对话。

### 两种写法对比

| | **写法 1：直接用 Agent** | **写法 2：create_app** |
|---|---|---|
| **需要 server** | ❌ 不需要 | ✅ 需要 |
| **需要 WebUI** | ❌ 不需要 | ✅ 需要 |
| **代码量** | 少（一个脚本） | 多（配置 + 启动） |
| **调试方式** | 直接 `python xxx.py` | WebUI 对话 |
| **适合场景** | 开发调试、脚本、后端集成 | 产品化、多用户 |
| **多 Agent** | 每个写一个脚本 | 注册多个模板 |

## 六、WebUI 使用

### 6.1 WebUI 是干嘛的

WebUI 是一个**可视化的 Agent 管理 + 对话界面**，功能包括：

| 功能 | 说明 |
|------|------|
| **创建 Agent** | 填表单配置 name、model、system prompt、tools |
| **对话测试** | 聊天界面，实时看 Agent 回复 |
| **工具调用可视化** | 看 Agent 调了哪些工具、参数、结果 |
| **权限审批** | human-in-the-loop 时点"允许/拒绝" |
| **定时任务** | 配置定时执行的 Agent 任务 |
| **知识库管理** | 上传文档、管理 RAG 知识库 |
| **MCP 管理** | 配置 MCP Server 连接 |

```bash

# 2. 启动 Python 后端
cd examples/agent_service

# 3. 启动 WebUI

# 4. 浏览器打开 http://localhost:5173
```

### 6.3 怎么用 WebUI 调试自定义 Agent

**核心问题**：WebUI 只能调试通过 `create_app()` 注册的 Agent，不能直接连你独立写的 Agent 代码。

**解决办法**：

#### 方案 A：把你的 Agent 注册到 create_app（推荐）

```python
# main.py
from agentscope.app import create_app, SubAgentTemplate

app = create_app(
    custom_subagent_templates=[
        SubAgentTemplate(
            type="pregnancy_advisor",
            description="孕产顾问",
            system_prompt_template="你是孕产顾问...",  # 从你的代码抄过来
        ),
        SubAgentTemplate(
            type="nutritionist",
            description="营养师",
            system_prompt_template="你是营养师...",  # 从你的代码抄过来
        ),
    ],
)
```

然后启动 `main.py` + WebUI，在 WebUI 里选择你的 Agent 类型创建实例。

## 八、官方文档说法

根据官方文档（https://docs.agentscope.io/latest/en/deploy/agent-service）：

### 官方定义

**`create_app` 是 AgentScope 提供的核心函数，用于构建基于 FastAPI 的 Agent 托管服务。**

它将你写的 Agent 代码转化为**支持多租户、多会话的 HTTP 生产级服务**。

### 官方示例

```python
import uvicorn
from agentscope.app import create_app
from agentscope.app.storage import RedisStorage
from agentscope.app.message_bus import RedisMessageBus
from agentscope.app.workspace_manager import LocalWorkspaceManager

# 1. 配置存储
storage = RedisStorage(host="localhost", port=6379)

# 2. 配置消息总线
message_bus = RedisMessageBus(host="localhost", port=6379)

# 3. 配置工作区管理器
workspace_manager = LocalWorkspaceManager(
    basedir="/data/workspaces",
    ttl=3600.0,
)

# 4. 创建 FastAPI 应用
app = create_app(
    storage=storage,
    message_bus=message_bus,
    workspace_manager=workspace_manager,
)

# 5. 启动服务
uvicorn.run(app, host="0.0.0.0", port=8000)
```

### 官方说的自定义 Agent 方式

| 方式 | 说明 |
|------|------|
| **REST API** | `POST /agent` 创建 Agent 配置（显示名、system prompt、运行时配置） |
| **SubAgentTemplate** | 在 `create_app` 里注册子代理模板，Leader Agent 可以动态生成 |
| **extra_agent_tools** | 动态注入自定义工具（按 user/agent/session） |
| **extra_agent_middlewares** | 动态注入自定义中间件 |

### 官方文档的关键点

> **当前页面主要侧重于 Agent Service（部署与托管层），而不是底层 Python Agent 类的代码级编写。**

**底层 Agent 编写**参考：`Agent` 构建块章节

## 十、完整示例：孕产助手

### 10.1 MCP Server

```python
# pregnancy_mcp.py
from mcp.server import FastMCP
from pydantic import BaseModel, Field

mcp = FastMCP("孕产助手")

class PregnancyInfo(BaseModel):
    weeks: int = Field(description="当前孕周")
    symptom: str = Field(default="", description="当前症状")

@mcp.tool()
def pregnancy_advisor(info: PregnancyInfo) -> str:
    """根据孕周和症状给出建议。"""
    advice = f"当前孕{info.weeks}周。"
    if info.weeks < 12:
        advice += "孕早期注意补充叶酸，避免剧烈运动。"
    elif info.weeks < 28:
        advice += "孕中期注意营养均衡，按时做唐筛和大排畸。"
    else:
        advice += "孕晚期注意数胎动，准备待产包。"
    if info.symptom:
        advice += f"\n关于症状「{info.symptom}」：建议咨询产科医生。"
    return advice

@mcp.resource("guide://trimester/{trimester}")
def trimester_guide(trimester: str) -> str:
    """获取孕三期注意事项"""
    guides = {
        "孕早期": "1.补充叶酸 2.避免辐射 3.注意休息",
        "孕中期": "1.均衡饮食 2.适量运动 3.按时产检",
        "孕晚期": "1.数胎动 2.准备待产包 3.注意临产信号",
    }
    return guides.get(trimester, "请确认孕阶段")

if __name__ == "__main__":
    mcp.run(transport="streamable-http", port=8000)
```
